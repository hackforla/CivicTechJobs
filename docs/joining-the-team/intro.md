# Joining the Team

Welcome to CivicTechJobs. This guide gets you oriented as a new contributor.

## Onboarding steps

1. Confirm you've completed Hack for LA's [Guide for New Volunteers](https://www.hackforla.org/getting-started).
2. Read the [project README](https://github.com/hackforla/CivicTechJobs/blob/main/README.md).
3. Check the [Hack for LA project board](https://github.com/orgs/hackforla/projects/37) for current open roles and active issues.
4. Drop into the `#civictechjobs` Slack channel to introduce yourself; a maintainer will help point you at the right starting place.

## Role-specific guides

Pick the page that matches your role:

- [UI/UX Designer](uiux-designer.md)
- [UI/UX Researcher](uiux-researcher.md)
- Web Developer: see [CONTRIBUTING.md](https://github.com/hackforla/CivicTechJobs/blob/main/CONTRIBUTING.md) for the developer onboarding flow. The developer path lives in CONTRIBUTING.md rather than here because dev onboarding is mostly mechanics (fork, branch, lint, PR), and CONTRIBUTING is where mechanics live for any contributor type.

If your role isn't listed (e.g., Product Manager, content writer), reach out in `#civictechjobs` and a maintainer will point you at the right starting place.

## Accessibility expectations

CivicTechJobs targets WCAG 2.2 Level AA compliance, in line with [Title III of the ADA](https://www.ada.gov/pcatoolkit/chap5toolkit.htm). All contributors should be familiar with the basics; the developer-specific guidance is in [design-system.md](../developer/design-system.md).
